# -Image-Fusion-using-Discrete-Wavelet-Transform-DWT-
This project focuses on image fusion, a method used to combine multiple images of the same scene into a single, comprehensive version that is more informative than the originals. By employing the Discrete Wavelet Transform (DWT), the system breaks each image down into low-frequency components, which represent smooth structures like the background, and high-frequency components, which capture sharp details like edges and textures.
+4

These separate elements are then merged using specific logic, such as the MaxMax or MinMax strategies, to ensure the most significant details from each source are preserved. Finally, an inverse transform is applied to reconstruct a fused image that boasts improved clarity and contrast, making this technique highly valuable for fields like medical diagnostics and satellite surveillance.
